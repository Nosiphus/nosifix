# NosiFix
NosiFix adds a random assortment of fixes for other mods that have not been updated by their authors.

# Current Fixes
[Chisels & Bits](https://www.curseforge.com/minecraft/mc-mods/chisels-bits): NosiFix allows users to unpin the Chisels & Bits resource pack from the top of the list, which allows users of modded resource packs, such as Sphax PureBDcraft, to use their modded textures instead of being forced to utilize the vanilla textures.

[WTHIT](https://www.curseforge.com/minecraft/mc-mods/wthit-forge): NosiFix implements [PR #372](https://github.com/badasintended/wthit/pull/372), which fixes an issue where the block capability would display the information for the first block you looked at for every subsequent block and would never change.
